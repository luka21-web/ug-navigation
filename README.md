# ატვირთვის ინსტრუქცია (GitHub)

ოთხივე ფაილი ატვირთე რეპოზიტორიის მთავარ საქაღალდეში, `data.json`-ის გვერდით.
არსებული ფაილები ჩაანაცვლე.

| ფაილი | რა შეიცვალა |
|---|---|
| `index.html` | ყოფილი `index(9).html` — „მორიგეობის კალენდარი“. დიზაინი და ლოგიკა იგივეა; მონაცემს `data.json`-იდან იღებს |
| `duty.html` | სრული სივრცე; მონაცემს `data.json`-იდან იღებს და 5 წუთში ერთხელ ამოწმებს |
| `data-loader.js` | `data.json`-ის წამკითხველი (ორივე გვერდი იყენებს) |
| `bridge-index9.js` | „ხიდი“ `data.json`-სა და `index.html`-ს შორის |

`students-guide.html` არ შეცვლილა — დატოვე როგორც არის.

## თუ data.json სხვა ადგილასაა
- `bridge-index9.js` → მე-11 ხაზი: `var DATA_URL = 'data.json';`
- `duty.html` → მოძებნე `UG_DATA_URL` და ბრჭყალებში ჩაწერე მისამართი.

## შემოწმება
- `index.html` — ქვედა მარჯვენა კუთხეში: „Google Sheets · განახლდა HH:MM“.
  წითელი წარწერა („data.json ვერ ჩაიტვირთა“) ნიშნავს, რომ data.json არ არსებობს ან სწორი JSON არ არის — გვერდი მაშინ ბოლო ცნობილ მონაცემებს აჩვენებს.
- `duty.html` — ზედა ზოლში მწვანე „ცოცხალი“; გრაფიკის ქვემოთ: „მონაცემები Google Sheets-იდან“.
- F12 → Console — გაფრთხილებები (მაგ. „ცვლა ვერ წავიკითხე“) აქ ჩანს.
